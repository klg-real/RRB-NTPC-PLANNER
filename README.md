# 🚀 RRB NTPC AI Study Planner & Companion

A modern, full-stack RRB NTPC exam study tracker styled with **Astro + Crux** cosmic dark theme and powered by **Gemini AI**.

## 🌟 Key Features
- **Official Syllabus Checklist**: Tracks progress for CBT-1 & CBT-2 General Awareness, Math, and Reasoning.
- **AI Revision Notes Generator**: Powered by Google Gemini API to produce quick formulas and tricks.
- **Mock Performance Dashboard**: Graph-based test tracking with score & accuracy metrics.
- **Pomodoro Focus Launcher**: Integrated study timer with customizable focus periods.
