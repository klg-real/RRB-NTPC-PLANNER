## 🌟 Features

* **Official Syllabus Tracker:** Preloaded CBT-1 & CBT-2 syllabus checklist across Mathematics, General Intelligence & Reasoning, and General Awareness. Automatically persists progress in local storage.
* **Gemini AI Mentor:** Generates instant formula cheat sheets, time-saving tricks, and topic-specific practice MCQs with explanations.
* **Mock Test Performance Analytics:** Log test scores and track accuracy over time with real-time Chart.js visual analytics.
* **Pomodoro Focus Timer:** Built-in focus launcher with custom study and break intervals.
* **Astro + Crux Cosmic UI:** Glassmorphism dashboard with cyber-space aesthetics and animated starry canvas backdrop.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Tailwind CSS - Astro + Crux UI), JavaScript ES6+, Chart.js, LocalStorage API
* **Backend:** Python (Flask), `google-genai` SDK
* **AI Model:** Google Gemini 2.5 Flash
* **Deployment & WSGI:** Render & Gunicorn
